# ♡ Queques Vivi

Sitio web para una pastelería y repostería, con catálogo y formulario de consultas de encargos.

## Cómo abrirlo

Abrí `index.html` en un navegador. No requiere instalaciones.

## Antes de publicarlo

1. En `script.js`, cambiá `const WHATSAPP_NEGOCIO = "";` por el número real del negocio en formato internacional **sin + ni espacios**, por ejemplo `"50688888888"` (número ficticio).
2. Revisá los productos ofrecidos y las descripciones; son propuestas iniciales y no un catálogo confirmado.
3. Si querés, reemplazá las ilustraciones en `imagenes/` por fotos reales de productos.
4. Probá el formulario y el enlace de WhatsApp desde el celular.

## Cómo se envían las fotos

La persona puede seleccionar una foto y verla en la página. Por seguridad y limitaciones de los enlaces `wa.me`, la foto **no se envía automáticamente** a WhatsApp: la persona debe adjuntarla manualmente al chat una vez abierto. No se guarda la imagen en ningún servidor.

## Archivos

- `index.html`: estructura y formulario.
- `estilos.css`: diseño adaptable a celular.
- `script.js`: vista previa de archivos, validación y mensaje de WhatsApp.
- `imagenes/`: ilustraciones locales de los productos.

El sitio no procesa pagos ni confirma pedidos automáticamente: sirve para iniciar una conversación y solicitar una cotización.
